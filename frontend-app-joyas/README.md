# frontend-app-joyas
This is the frontend app for the **Desafío 5 - Tienda de joyas** and was made with React + Vite + TypeScript.

I used Bootstrap to layout the styles.

## How to use
All is said in [**General Project README**](../README.md), but to summarize, the requirements to run the frontend app in dev mode:

1. Install dependency packages in a terminal in the frontend root path running:

    ```bash
    $ npm install
    ```

2. Create a .env file and specify the backend PORT (default port is 3000 by the way).

3. Start the app with the following command:

    ```bash
    $ npm run dev
    ```

4. Visit **http://localhost:5173** to see the home page.
